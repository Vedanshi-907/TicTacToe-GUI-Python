# 🎮 Tic Tac Toe - Python GUI Game

A simple desktop Tic Tac Toe game built using Python and Tkinter.  
This is a 2-player game where players take turns marking X and O on a 3x3 grid.

---

## 🚀 Features

- 2-player mode (X and O)
- Interactive GUI using Tkinter
- Winner detection logic
- Highlights winning combination
- Simple and lightweight desktop application

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI library)

--
